# 共鸣 · StepFun forks

本账号维护 [revoice-resonance](https://github.com/revoice-resonance) 项目的 StepFun 接入分支，供基础沟通流程开发与验证。

- [Web 前端与 Worker](https://github.com/Zgh332358/web-app)
- [Go 任务后端](https://github.com/Zgh332358/backend)
- [Python 转写与语料服务](https://github.com/Zgh332358/asr)
- [iOS 外壳](https://github.com/Zgh332358/ios-app)

使用官网 `https://api.stepfun.com/v1`，分别接入 `step-5-preview`、`stepaudio-3-chat-preview` 与 `stepaudio-3-tts`。API Key 由运行者在服务端配置。实际效果与模型权限仍需真实 Key 和用户语音验证。

[完整配置、仓库职责与验证边界](https://github.com/Zgh332358/.github#readme)。原组织的 `tts` 仓库为空，GitHub 不允许 fork；合成能力在 Web 和 Go 后端实现。
